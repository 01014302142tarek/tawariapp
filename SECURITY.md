# Security Policy

## Reporting a Vulnerability
Please use GitHub Security Advisories for private reporting.
- Go to the repository → Security → Advisories → "New draft security advisory"

If that is not possible, contact the repo owner directly.

## Scope
- Authentication, authorization, and session handling
- Any data access involving patient or doctor records
- Payments and billing flows
- File uploads and document generation

## Expectations
- Do not publicly disclose until a fix is released
- Provide clear reproduction steps and impact assessment
